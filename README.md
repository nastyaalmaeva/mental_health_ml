# Прогнозирование ментального здоровья студентов

## О проекте

Сравнение методов машинного обучения для предсказания вероятности депрессии и тревожности у студентов.

**Методы:** линейная регрессия, случайный лес, XGBoost, нейронная сеть.

## Результаты (R² на тестовой выборке)

| Модель | Депрессия | Тревожность |
|--------|-----------|-------------|
| Линейная регрессия | 0.90 | 0.72 |
| Случайный лес | 0.91 | 0.90 |
| XGBoost | 0.97 | 0.95 |
| Нейронная сеть | 0.98 | 0.95 |

Лучшая модель — **XGBoost**.

## Скрипты

1. `eda_analysis.py` — анализ данных
2. `data_preproccesing.py` — предобработка
3. `train_*.py` — обучение моделей
4. `evaluate_models.py` — сравнение результатов

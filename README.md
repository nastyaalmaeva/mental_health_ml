# Прогнозирование ментального здоровья студентов методами машинного обучения

## Описание
Сравнение линейной регрессии, случайного леса, XGBoost и нейронной сети для предсказания вероятности депрессии и тревожности.

## Структура
- `src/` — все скрипты для EDA, предобработки, обучения и оценки
- `models/` — обученные модели (игнорируются git)
- `plots/` — все графики
- `data/` — исходный датасет

## Запуск
1. Установить зависимости: `pip install -r requirements.txt`
2. Поместить `mental_health.csv` в `data/`
3. Запустить скрипты по порядку: `01_eda_analysis.py` → `02_preprocessing.py` → ...
4. Результаты в `plots/` и `results/`

## Результаты
Лучшая модель — XGBoost (R² депрессия: 0.971, тревожность: 0.949)
